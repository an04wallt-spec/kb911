# KB911

KB911 — компактное Windows-приложение для оформления листов по изображениям: размеры, надписи, рамка, логотип и экспорт.

## Windows

Приложение собирается в один `KB911.exe` и использует Microsoft Edge WebView2 Runtime, который обычно уже установлен в Windows 10/11.

### Сборка

GitHub Actions автоматически собирает `KB911.exe` после изменений в ветке `main`. Готовый EXE появляется в артефакте `KB911-Windows`.

### Поведение окна

Стартовый формат — A4 горизонтальный. Окно подстраивается под выбранный формат листа; когда размер ограничен рабочей областью монитора, лист автоматически уменьшается по масштабу, оставаясь целиком видимым.
